# Decision framing template

Use this when the user brings a vague or broad issue.

```markdown
## Reframed decision question
<What decision needs to be made, by whom, by when, and against which success metric?>

## Objective
<What the organization wants to achieve.>

## Scope
**In scope**
- 

**Out of scope**
- 

## Decision-maker
<Who owns the final decision.>

## Stakeholders
| Stakeholder | Role in decision | Main concern |
|---|---|---|
|  |  |  |

## Constraints
| Constraint | Hard or soft? | Implication |
|---|---|---|
|  |  |  |

## Success metric
| Metric | Target | Time horizon |
|---|---|---|
|  |  |  |

## Decision criteria
| Criterion | Why it matters | Weight / priority |
|---|---|---|
|  |  |  |

## Missing information
| Missing information | Why it matters | How to get it quickly |
|---|---|---|
|  |  |  |

## Working assumption
<If information is missing, state the assumption used to continue.>
```
