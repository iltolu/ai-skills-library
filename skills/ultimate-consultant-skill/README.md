# Ultimate Consultant Skill

This is a Claude Skill package for senior-consultant style problem solving.

## Contents

- `SKILL.md` — main skill instructions and activation metadata
- `references/framework-catalog.md` — detailed framework library
- `references/framework-selection-map.md` — framework routing and combinations
- `references/quality-and-ethics-standards.md` — quality, uncertainty, and stakeholder safeguards
- `templates/` — reusable output templates
- `examples/` — examples of good consultant-style output
- `evals/eval-prompts.md` — prompts to test the skill
- `scripts/README.md` — placeholder for optional scripts

## Recommended use

Download this folder as a ZIP file and upload it to Claude Skills. Start with the existing version, test with the eval prompts, then refine the `description` field if the skill triggers too often or not often enough.
