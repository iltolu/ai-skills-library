# Framework selection map

Use this file to choose the right framework for the user's problem. The rule is simple: use the smallest useful framework that helps the user decide or act.

## Selection principles

1. Start with the user need, not the favorite framework.
2. Use one primary framework and one or two supporting frameworks.
3. Do not stack frameworks without a reason.
4. If the problem is vague, frame the decision first.
5. If the problem is complex, structure it before analyzing it.
6. If the problem is execution-heavy, include stakeholders, ownership, and adoption.
7. If the decision is high-stakes, include assumptions, confidence, stakeholder impact, and human review.

## Routing table

| User situation | Best primary framework | Supporting tools | Typical output |
|---|---|---|---|
| “This topic is vague” | Problem framing | Decision criteria | Decision question |
| “Help me structure this” | MECE / issue tree | 80/20 | Workstreams / analysis plan |
| “Why is this happening?” | Issue tree / 5 Whys | Evidence log | Root-cause diagnosis |
| “What should we focus on?” | 80/20 | Impact-control matrix | Prioritized actions |
| “We need a recommendation” | SCQA / Pyramid | Options comparison | Executive memo |
| “Should we choose A, B, or C?” | Decision tree | Sensitivity analysis | Decision recommendation |
| “Should we enter this market?” | Five Forces | 3Cs, market sizing | Market-entry view |
| “How do we grow?” | 3Cs / 4Ps | Segmentation | Growth plan |
| “How do we improve margin?” | Value chain | 5 Whys, driver tree | Margin-improvement plan |
| “What strategic options do we have?” | TOWS | SWOT, 3Cs | Ranked options |
| “How do we implement this?” | Stakeholder map / RACI | OKRs | Execution plan |
| “Our organization is misaligned” | 7-S | Stakeholder map | Alignment diagnosis |
| “People are not adopting the change” | ADKAR / influence model | Kotter | Change plan |

## Common framework combinations

### Strategy and market entry

Use this sequence:

1. Problem framing
2. MECE issue tree
3. Hypothesis-driven testing
4. Five Forces
5. 3Cs
6. SCQA recommendation

Best for:
- market entry
- category attractiveness
- competitive positioning
- strategic options

Avoid using only SWOT. SWOT should usually be a synthesis tool after the real analysis.

### Growth and go-to-market

Use this sequence:

1. Problem framing
2. 3Cs
3. Customer segmentation
4. 4Ps
5. 80/20 prioritization
6. SCQA recommendation

Best for:
- product launch
- demand generation
- pricing and packaging
- customer acquisition
- channel strategy

### Operations and margin improvement

Use this sequence:

1. Problem framing
2. Profit / cost driver tree
3. Value chain
4. 80/20 prioritization
5. 5 Whys on highest-impact pain points
6. Implementation plan

Best for:
- cost reduction
- margin pressure
- process bottlenecks
- service quality problems
- operational efficiency

### Transformation and implementation

Use this sequence:

1. SCQA to state the change case
2. Stakeholder map
3. RACI or decision-rights map
4. OKRs
5. 7-S diagnosis
6. ADKAR / influence-model change plan

Best for:
- operating model change
- reorganization
- governance redesign
- transformation rollout
- AI or ERP adoption

### Uncertain investment decision

Use this sequence:

1. Decision framing
2. Options definition
3. Decision tree
4. Sensitivity analysis
5. Risk and mitigation plan
6. Executive recommendation

Best for:
- build vs buy
- enter vs pilot vs wait
- investment prioritization
- make-or-buy
- scale vs stop

|---|---:|---:|---|
| Problem framing | Low | Low | Yes |
| MECE | Low | Low | Yes |
| Issue tree | Medium | Low-medium | Yes |
| 80/20 | Low | Low-medium | Yes |
| Hypothesis-driven | Medium | Medium | Yes |
| SCQA / Pyramid | Medium | Low | Yes for communication |
| Decision tree | Medium-high | Medium-high | Use after options are clear |
| Five Forces | Medium | Medium | Use for industry questions |
| Value chain | Medium | Medium-high | Use for operations / margin |
| 3Cs | Low | Low-medium | Good early strategy lens |
| 4Ps | Medium | Medium | Use for GTM / marketing |

| Change models | Medium-high | Medium | Use for adoption |

## Anti-routing rules

Do not use:

- Five Forces for an internal process problem.
- SWOT as the only framework for a serious strategy decision.
- 5 Whys for complex systemic problems without allowing branches.
- RACI when the real issue is decision rights or leadership conflict.
- OKRs when the strategy is not yet clear.
- Change models without a concrete behavior that must change.
- Issue trees without prioritization.
- SCQA without a clear answer.
